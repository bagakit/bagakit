# Guidebook

This guidebook is the reading map for the shared knowledge root.

## Read When Needed

- Read `must-authority.md` when the task needs shared-knowledge ownership or
  publication rules.
- Read `must-sop.md` when the task needs maintenance routes or shared
  directives.
- Read `must-recall.md` when the task needs prior decisions or facts.
- Read deeper topic pages only after the task identifies a relevant topic.

## Shared Root

- `docs`

## What Lives Here

- shared checked-in knowledge for this repository
- topic pages and topic directories
- system pages for progressive loading
- reusable-items governance and active catalogs when the repository uses them

## Reading Order

1. system pages
2. topic landing pages or top-level pages
3. deeper pages only when the task needs them
