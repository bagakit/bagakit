# Benchmark Memory

This surface holds durable benchmark observations promoted from non-gating
evaluation runs under `gate_eval/`.

Keep raw cases and run outputs in `gate_eval/`. Promote only reviewed,
source-bound observations and claim evidence here. Stable repository rules
belong in `docs/specs/`, and capability claims still require the review process
in `docs/stewardship/sop/capability-review-sop.md`.
