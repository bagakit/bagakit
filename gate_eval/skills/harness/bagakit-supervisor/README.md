## Claim Boundary

Do not claim frontier or general superiority from:

- deterministic receipt fixtures
- Agent-authored worker, route, or intervention fields
- one run per condition
- shared-workspace forward tests
- a repaired-in-place blind packet

The live protocol separates two questions:

1. On aligned work, does Supervisor avoid interference and bounded overhead?
2. On injected faults, does Supervisor prevent hard incidents with the smallest
   correction while preserving valid work?

The outcome-ownership cases add a third semantic question: does Supervisor
keep strict terminal proof while removing avoidable control-path delay, without
taking over Worker implementation or mistaking visible activity for progress?

Supervisor versus direct and Supervisor versus dispatch-only are separate
policy-bundle contrasts. The primary go/stop contrast is Supervisor versus
dispatch-only; neither isolates the causal effect of loading one skill.
