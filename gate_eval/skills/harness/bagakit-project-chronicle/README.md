# Project Chronicle Eval

`gate_eval/skills/harness/bagakit-project-chronicle/` is the non-gating
optimization surface for `skills/harness/bagakit-project-chronicle/`.

It carries eight sanitized serious-moment cases covering census honesty,
contradiction preservation, real generation boundaries, epic fidelity,
harness-learning transfer, dual-output coherence, route precision, and
promotion boundaries.

The current baseline/candidate result is a deterministic guard-coverage pilot.
Two case routes also have one fresh-agent calibration receipt. This is not a
full live-agent suite or a literary-quality score. The cases request three
trials with a minimum pass rate of `0.67` for future calibrated runs.

Run:

```bash
node --experimental-strip-types dev/eval/src/cli.ts run \
  --root . \
  --suite gate_eval/skills/harness/bagakit-project-chronicle/suite.ts
```

Default result root:

- `gate_eval/skills/harness/bagakit-project-chronicle/results/runs/`
