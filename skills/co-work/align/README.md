# Align

Own shared goals, assumptions, evidence, decisions, and knowledge before and
during collaboration. The canonical route and single-owner matrix is
[`docs/specs/skill-routing-contract.md`](../../../docs/specs/skill-routing-contract.md);
read it before composing more than one Align skill.

| Need | Owner | Handoff |
| --- | --- | --- |
| Live ambiguity or changing question | `bagakit-spark` | accepted snapshot or named next action |
| Durable options and decision package | `bagakit-brainstorm` | archived handoff artifact |
| Concrete branch stress-test | `bagakit-grill` | acceptance condition and branch disposition |
| Source-bound evidence | `bagakit-researcher` | claims/insights with source refs and limits |
| Checked-in shared knowledge | `bagakit-living-knowledge` | managed publication/recall receipt |
| Recoverable shared understanding | `bagakit-consensus-ledger` | embedded ledger only; parent owner remains authoritative |

These are alternate entry routes, not a mandatory sequence. A peer may provide
evidence or state, but it must return that packet to the listed owner and must
not close another skill's lifecycle.
