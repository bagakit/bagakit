# Learning Atlas

## Route

- High-density learning map with layered hierarchy, memory anchors, and media
  only where they improve retention.
- For interactive courses, use a three-zone workbench: navigation and progress,
  explanation and learner action, evidence and handoff.

## Good For

- Concept understanding, system understanding, or guided knowledge transfer.

## Control Treatment

- Favor structure, hierarchy, and checkpoints over operational tool chrome.
- Keep the current objective and learner action more prominent than progress
  decoration.
- On narrow screens, preserve zone order through tabs or a drawer.
- Use learner-facing language for local save, reset, provenance, and handoff;
  never expose storage APIs, skill ids, source file names, or build narration.

## Failure Signals

- The page becomes a wall of text.
- Decorative density replaces cognitive clarity.
- Completion metrics imply mastery without upstream evidence.
- Backstage production chrome enters the learner surface.
