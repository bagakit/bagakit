# Sprite Pipeline Round History

This file holds historical experiment evidence for escalation and review. It is
not required for ordinary asset generation.

- Baseline: attractive single-character renders and contact sheets do not prove
  source layout, game-layer separation, or batch consistency.
- Round 5: guided and no-guide full-row pairs produced zero strict motion passes;
  layout guides are not a proven motion contract.
- Round 7: simple raster skeleton guides preserved identity but achieved `0/4`
  intended phase matches under blind labeling.
- Round 8: pose exemplars preserved identity but the selected half-cycle failed
  continuity review; ordinary exemplar transfer is not structural control.
- Round 10B: deterministic cutout rigging from one raster canonical produced
  detached-leg artifacts; flattened rasters lack reusable occluded surfaces.
- Round 11: grouped core/arms/legs paper-doll sheets failed structural source
  gates and did not produce a reliably riggable kit.
- Round 12: angle ablation failed the source validator; camera angle was not the
  main cause of part-ownership failure.
- Round 13: the frozen SD1.5 + OpenPose ControlNet + IP-Adapter Plus route was a
  source failure; do not promote its outputs.
- Round 14: normalized identity input improved camera/background signals but the
  four-phase runtime result remained unusable.
- Round 15: depth won preregistration only after exact model, guide, receipt, and
  preflight constraints were frozen; execution remains approval-gated.
- Sedimentation rule: run the paper-doll source-kit validator before rig preview;
  manual ownership, mating-surface, identity, style, and camera gates remain
  separate from pixel validation.
