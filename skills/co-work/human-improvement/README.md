# Human Improvement Family

This family is reserved for learning, reflection, and human-improvement skills
that should co-evolve within the Bagakit monorepo.

Current skills:

- `bagakit-project-chronicle`
  - source-grounded project retrospectives and reusable lessons

- `bagakit-mastery-learning`
  - turns source material into bounded mastery contracts, diagnostic course
    routes, active practice, transfer checks, support fading, retention plans,
    learner-copy review through Writing Core, and optional HITL course handoffs
- `bagakit-explain`
  - turns unfamiliar or complex topics into visual-first HTML explanations that
    start from zero assumed knowledge, preserve a reusable architecture map,
    descend to causal roots, and use the learner's language; its conditional
    technical-architecture route explains real repository boundaries, paths,
    data/state changes, and recovery with evidence refs

Boundary:

- visual explanation helps a person form a durable mental model
- HITL may project that explanation into a human action or evidence surface;
  HITL still owns interaction, judgment, history, and handoff
- mastery learning adds diagnostics, adaptive practice, transfer evidence, and
  bounded mastery claims
