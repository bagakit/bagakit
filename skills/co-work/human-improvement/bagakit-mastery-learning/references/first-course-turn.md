# First Course Turn

Use this template for the first learner-visible response of a newly authored
interactive course. The full course packet may already exist, but it stays
behind this turn.

## Output Contract

Emit exactly three learner-facing blocks before waiting for the learner.

### Scope Receipt

- requested anchor and same-level stop boundary
- included dependency summary
- excluded or unresolved dependencies that limit complete-coverage claims

Do not summarize the source's core answers in this block.

### Evidence Receipt

State plainly:

- course authoring: ready
- learner capabilities: `not_assessed`
- near and far transfer: `not_assessed`
- delayed retention: `not_assessed`
- bounded mastery requires a changed-context unaided task and the declared
  delayed re-entry check

### Blind Diagnostic

- ask a small number of construction, explanation, prediction, or decision
  questions that sample generative prerequisites
- request reasoning where recognition could pass by guessing
- end by waiting for the learner's attempt

## Forbidden Before The Attempt

- course map or lesson sequence
- core mental model or source answer summary
- numerical anchors that answer the diagnostic
- worked examples, correct option keys, or prefilled answers
- any claim that the learner passed, completed, or mastered the course

Writing review may improve clarity and rhythm, but this three-block order and
the deliberate omissions above are protected meaning. A rewrite that previews
the course map, answer, numerical cue, or rubric before the attempt fails the
first-turn contract.

After the attempt, reveal only the branch needed by the evidence and preserve
the original response before feedback.
