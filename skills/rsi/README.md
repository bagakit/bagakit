# RSI

M2 improves the M1 Evolve process: how it observes trajectories, creates
candidates, chooses experiments, evaluates outcomes, and adopts changes.
Dreaming RSI is a planned approach to generating and testing improvements to
that process; it is not an implemented skill.

No installable RSI skill exists yet. This directory declares ownership and
does not materialize a runtime loop or state. See
`docs/architecture/D1-recursive-evolution-architecture.md`.
