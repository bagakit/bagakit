# Bagakit Project Chronicle

`bagakit-project-chronicle` edits a bounded set of project sessions into an
evidence-grounded epic chronicle and a reusable harness-evolution ledger.

## First Principle

Epic framing is an editorial lens, not evidence. Every generational claim,
reversal, role, or lesson must trace back to session evidence, and missing
coverage must remain visible.

## Owning Boundary

This skill owns session census, session-card compression, cross-session
lineage, function-based dramatic casting, chronicle editing, and reviewed
harness-evolution candidates.

It does not own raw transcript retention, host session APIs, Evolver topics or
promotion, shared knowledge publication, or model training.

## Runtime Surface Declaration

- top-level root when materialized:
  - `.bagakit/project-chronicle/`
- run root:
  - `.bagakit/project-chronicle/runs/<run-id>/`
- marker:
  - `.bagakit/project-chronicle/surface.toml`
- lifecycle:
  - reviewable project-local state; it may be ignored by Git

The installed runtime contract lives in `references/output-contract.md`.
The skill-goal review contract lives in
`references/chronicle-quality-contract.toml`.
Repository authority lives in `docs/specs/project-chronicle-contract.md`.

## Core Flow

1. Declare what “all sessions” means for this edition.
2. Register every discovered session and seal coverage honestly.
3. Compress included sessions into source-bound cards.
4. Derive generations, roles, corrections, and leverage points.
5. Edit `chronicle.md` while maintaining `evolution-ledger.json`.
6. Pass coverage, fidelity, non-fabrication, generational, harness-value, and
   privacy review gates.

## Composition

The skill may export reviewed candidates for repository evolution or shared
knowledge, but those handoffs remain optional and do not create topics, routes,
promotions, or durable shared truth by themselves.
